Tus datos

Para ver y editar los mismos portafolios en el celular y en la compu, guardalos en tu repo de GitHub. Se hace una vez por dispositivo:

  1. Abrí GitHub → nuevo token (fine-grained).
  2. Token name: portafolios. Expiration: la que quieras (hasta 1 año).
  3. Repository access: Only select repositories → .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Tocá Generate token, copialo y pegalo acá abajo.

Con GitHub conectado, los portafolios quedan en data/portfolio.json de tu repo, que es público: cualquiera con el link puede verlos, pero solo vos podés editarlos.
